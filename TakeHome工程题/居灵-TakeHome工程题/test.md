# 居灵-TakeHome工程题
## 角色身份
你是一个专业的C#全栈开发人员，负责解决居灵-TakeHome工程题，你需要根据给定的轮廓和物体尺寸，判断是否可行将物体摆放在轮廓内，且不与轮廓及其他物体重叠，还需要做出可视化界面
## 项目技术
- 前端：html, css, js
- 后端：C# .NET Core
## 问题描述
给定一个轮廓及若干长宽的矩形物体，要求将这些物体摆放在轮廓内，且不与轮廓及其他物体重叠。
物体可以旋转，但是需与轮廓边平行或垂直摆放。
在空间充足的情况下，优先考虑所有物品均贴墙放置。
物品不可遮挡门的位置，且内开门会占据N x N的空间。N为门的宽度。

## 输入和输出
### 输入样例参考如下4个json文件, 请务必查看每个文件的内容
- /example1.json
- /example2.json
- /example3.json
- /example4.json
### 对应CAD图片如下4个png文件, 请务必查看每个文件的内容
- /image01.png
- /image02.png
- /image03.png
- /image04.png

Input: 
初始条件:
1. 轮廓形状: [(x1, y1) ..., (xN,yN)]表示轮廓线段的若干个点. 线段首尾相连
2. 门的位置: [(x1, y1), (x2, y2)]，表示门的两端点坐标
3. 门的类型: note 如果是内开门的话, 会占据1x1的空间
4. 摆放K件东西: {item1: (length, width), item2: (length, width) ... itemK: (length, width)} length和width为物体的尺寸
5. 物品类型
    fridge：冰箱
    shelf: 货架
    overShelf: 离地架
    iceMaker: 制冰机

Notes/Guides:
1. 冰箱length的其中一边为开门边，开门边不能放任何东西
2. 货架的边可以放东西

Output:
是否可行
K个物体的中心点坐标和旋转角度(给定尺寸的初始角度为0度). 

## 项目其他要求
- 由于是从企业真实场景中提取的，所以需要考虑一些实际问题，比如物体的尺寸是否符合实际，是否需要考虑物品的重量等。更多的站在业务的角度或者站在产品的角度去思考求出来的结果是否符合实际。
- 按照题目要求，需要判断是否可行，如果可行，需要输出K个物体的中心点坐标和旋转角度(给定尺寸的初始角度为0度)，如果不可可行，需要输出不可行的原因。
- 项目需要考虑性能问题，比如输入的轮廓和物体尺寸是否很大，是否需要优化算法。
- 项目需要考虑可扩展性，比如是否需要支持更多的物体类型，是否需要支持更多的门类型等。
- 一定要有前端可视化界面
